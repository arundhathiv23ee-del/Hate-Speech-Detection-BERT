# Hate-Speech-Detection-BERT
Hate speech detection using NLP and BERT-based text classification.
## About the Project

This project focuses on detecting hate speech in social media text using Natural Language Processing (NLP) and BERT-based text classification.

The project uses a BERT model to classify text into two categories:
- Hate Speech
- Non-Hate Speech

## Technologies Used

- Python
- Natural Language Processing (NLP)
- BERT
- Hugging Face Transformers
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- Google Colab

## Project Workflow

1. Load and prepare the dataset
2. Preprocess the text data
3. Split the dataset into training and testing data
4. Tokenize the text using a BERT tokenizer
5. Fine-tune the BERT model for text classification
6. Evaluate the trained model
7. Test the model with text inputs

## Project Files

- `hatespeech1.ipynb` – Complete Google Colab notebook containing the project implementation
- `requirements.txt` – Python libraries required for the project
- `README.md` – Project documentation

## How to Run

1. Open `hatespeech1.ipynb` in Google Colab.
2. Install the required libraries using `requirements.txt`.
3. Run the notebook cells in order.
4. Train and evaluate the BERT model.
5. Test the model with text inputs.
